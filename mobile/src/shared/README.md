# Shared Code Directory

This directory contains cross-cutting, reusable modules used across multiple features and screens.

## Subdirectory Structure

- `components/`: Generic presentational UI widgets (buttons, status badges, modals, cards).
- `theme/`: Styling design system tokens, color palettes, spacing metrics, and typography rules.
- `constants/`: Global application constants and configuration values.
- `hooks/`: Reusable custom React hooks for state, animation, and events.
- `utils/`: Pure helper utility functions and formatting helpers.
