# Features Module Directory

This directory contains domain-specific business modules for the Smart Home Monitoring & Control System.

## Module Responsibilities

- `dashboard/`: Home command center overview widgets and quick status summaries.
- `floors/`: Interactive floor plan visualization and matrix grid overlay controls.
- `devices/`: Heterogeneous device control interfaces (outlets, multi-switch units, hazard appliances, lights).
- `schedules/`: Appliance operating schedules and hazard timer cutoff configurations.
- `cameras/`: Security camera surveillance feeds and snapshot visualizers.
- `reports/`: Historical device usage analytics and energy metrics.
- `notifications/`: Audit trail for safety alerts, cutoff triggers, and system messages.
- `settings/`: App preferences, cloud connection options, and system reset controls.
