# Contributing Guidelines

Thank you for contributing to the Smart Home Monitoring & Control System project!

## Branching Conventions

- `main`: Production-ready releases.
- `develop`: Integration branch for team features.
- `feature/<feature-name>`: Branch off `develop` for individual features or fixes.

## Pull Request Process

1. Ensure code follows formatting and linting conventions.
2. Submit a Pull Request (PR) targeting the `develop` branch.
3. Obtain review and approval from at least one team member prior to merging.
4. Keep commits clean and informative.
